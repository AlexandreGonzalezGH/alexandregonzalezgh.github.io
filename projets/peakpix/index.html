PeakPix Application web Symfony de galeries de photos de sommets

Période
1er semestre 2026
Cours
CSC4101, Télécom SudParis
Outils
Symfony 6.4, Doctrine, Twig

Application web pour les passionnés de montagne. Chaque membre répertorie ses photos de sommets (nom, altitude, massif, coordonnées GPS) dans un album privé, puis en expose une sélection sur des murs publics ou privés. Une photo peut figurer sur plusieurs murs.

Ce qui est implémenté

  • Authentification par formulaire, rôles utilisateur et administrateur
  • Modèle Doctrine : Member, Album, SummitPic, Wall, avec relations OneToOne, OneToMany et ManyToMany
  • Envoi d'images avec VichUploaderBundle, jeu de données de démonstration, tests fonctionnels PHPUnit

Suite logique

  • Un Voter Symfony pour restreindre la modification d'un mur à son propriétaire
  • Vérifier qu'un mur est publié avant d'afficher une de ses photos
  • Page d'inscription

Modèle de données

  • Member1 — 1Album
  • Album1 — *SummitPic
  • Wall* — *SummitPic
  • Member1 — *Wall
